# Database Migrations & Seed Data Generation

`crank` provides first-class CLI subcommands for managing relational database migrations and generating realistic fake seed data.

---

## Part 1: Schema Migrations with `golang-migrate`

Crank wraps `golang-migrate` under the `crank migrate` subcommand so you don't need to manually install or configure separate migration CLI binaries.

### Creating Migrations

When you run `crank make scaffold <Model>`, Crank creates timestamped `.up.sql` and `.down.sql` files in `db/migrations/` alongside the generated code. To create standalone migrations, use `golang-migrate` directly via `crank migrate`:

```bash
# Generate a custom migration file (using golang-migrate directly)
migrate create -ext sql -dir db/migrations -seq add_category_to_products
```

This creates:
- `db/migrations/20260723200000_add_category_to_products.up.sql`
- `db/migrations/20260723200000_add_category_to_products.down.sql`

Edit the SQL files to define DDL changes:

```sql
-- Up Migration
ALTER TABLE products ADD COLUMN category VARCHAR(100) DEFAULT 'general';

-- Down Migration
ALTER TABLE products DROP COLUMN category;
```

### Running Migrations

Execute migration operations directly via Crank:

```bash
# Run all pending up migrations
crank migrate up

# Roll back the last migration step
crank migrate down 1

# Check current migration version
crank migrate version

# Force set migration version (e.g. after resolving conflict)
crank migrate force 20260723200000
```

> [!TIP]
> `crank migrate` reads your database connection string directly from `.env` (`DATABASE_URL`). You can override this using the `--database-url` flag:
> ```bash
> crank migrate up --database-url="postgres://user:pass@localhost:5432/mydb?sslmode=disable"
> ```

## Part 2: Seed Data Generation

Seeding realistic fake data into your database is effortless with `crank make seed`.

### 1. Generating Seed Files for Models

Crank parses your Go aggregate struct definition and automatically generates fake data fields based on model names and column types:

```bash
# Generate 50 realistic rows of fake User seed data
crank make seed User --count 50

# Generate an empty seed template file
crank make seed
```

This writes a Go seed runner script in `internal/adapters/persistence/gorm/seeds/`:

```go
// Code generated by crank make seed. DO NOT EDIT.
package seeds

import (
	"context"
	"github.com/brianvoe/gofakeit/v6"
	"gorm.io/gorm"
	"myapp/internal/domain/user"
)

func SeedUsers(db *gorm.DB, count int) error {
	for i := 0; i < count; i++ {
		u := user.User{
			ID:        uuid.New(),
			Name:      gofakeit.Name(),
			Email:     gofakeit.Email(),
			Role:      gofakeit.RandomString([]string{"admin", "editor", "user"}),
			CreatedAt: time.Now(),
		}
		if err := db.Create(&u).Error; err != nil {
			return err
		}
	}
	return nil
}
```

### 2. Executing Seeds

Insert seed records into your target database:

```bash
# Run all seed functions
crank make seed up
```

Crank connects to PostgreSQL using GORM, executes your seed functions inside a transaction, and reports inserted row counts.

---

## Summary of Migration & Seed Commands

| Command | Purpose |
| --- | --- |
| `crank migrate up` | Applies all pending database migrations. |
| `crank migrate down [N]` | Rolls back N database migration steps. |
| `crank make seed <Model> --count N` | Generates a fake data seed script for `Model`. |
| `crank make seed up` | Executes all seed scripts against the database. |
